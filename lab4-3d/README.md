У `reference/` лежить еталонна модель (`digit7.scad` → `digit7_reference.stl`,
`digit7_preview.png`) з тими самими розмірами. Вона потрібна лише для звірки:
лабораторну роботу виконують в AutoCAD і Fusion 360, як вимагає методичка.

## 1. Розміри (однакові для обох САПР)

Контур цифри «7» (мм, початок координат — лівий нижній кут габариту):

| Точка | X | Y |
|---|---|---|
| P1 | 0 | 100 |
| P2 | 70 | 100 |
| P3 | 70 | 82 |
| P4 | 38 | 0 |
| P5 | 14 | 0 |
| P6 | 46 | 78 |
| P7 | 0 | 78 |

- Товщина цифри: **8 мм**.
- Верхня планка 70 × 22 мм. Діагональ шириною ≈ 22 мм іде під кутом **68.2°**
  від точки (26, 0) до (58, 80).

| Текст | Операція | Шрифт / висота | Розташування | Глибина |
|---|---|---|---|---|
| МИКИТИЧ | опуклий (Join / UNION) | Arial Bold, 7 мм | по центру верхньої планки, центр (35, 89) | +1.5 мм над верхньою гранню |
| МИХАЙЛО | увігнутий (Cut / SUBTRACT) | Arial Bold, 5.5 мм | уздовж діагоналі, поворот 68.2°, центр ≈ (37.7, 40.6) | 2 мм углиб |
| ВАСИЛЬОВИЧ | наскрізний (Cut / SUBTRACT) | Arial Bold, 5 мм | уздовж діагоналі, поворот 68.2°, центр ≈ (45.5, 37.5) | 10 мм (більше за товщину 8 мм) |

> Шрифт має підтримувати кирилицю (Arial, Calibri). Шрифти SHX в AutoCAD
> (txt.shx) кирилицю не показують, тому потрібен TrueType.
>
> У наскрізному тексті внутрішні «острівці» букв (О, В, А, Ь) випадуть.
> Це властивість наскрізного вирізу, і про неї варто написати у висновку.

## 2. AutoCAD (Етап 1)

1. `UNITS` → мм. Робочий простір **3D Modeling**, вигляд `PLAN` (Top).
2. Контур: `PLINE` → ввести точки P1…P7 → `C` (замкнути).
3. `REGION` → вибрати полілінію (з'явиться «1 Region created»).
4. `EXTRUDE` → регіон → висота `8`.
5. Перенести UCS на верхню грань: `UCS` → `Z` 8 (або `UCS` → Face).
6. Текст: `STYLE` → створити стиль з Arial Bold. `TEXT` → Justify `MC` → точка → висота → кут → рядок:
   - МИКИТИЧ: точка `35,89`, висота `7`, кут `0`;
   - МИХАЙЛО: точка `37.7,40.6`, висота `5.5`, кут `68.2`;
   - ВАСИЛЬОВИЧ: точка `45.5,37.5`, висота `5`, кут `68.2`.
7. Перетворити текст на контури: `TXTEXP` (Express Tools) → `REGION` для отриманих кривих.
   Якщо `TXTEXP` недоступний: `EXPLODE` тексту не працює, тоді обвести букви через `BOUNDARY`.
8. Об'єм:
   - прізвище: `EXTRUDE` регіонів на `1.5` → `UNION` з цифрою;
   - ім'я: `EXTRUDE` на `-2` (всередину) → `SUBTRACT` (цифра мінус текст);
   - по батькові: `EXTRUDE` на `-10` (або перенести на Z=-1 і `11`) → `SUBTRACT`.
   Внутрішні контури букв (О, А…) вирізаються як окремі регіони: спочатку
   `SUBTRACT` внутрішнього регіону з зовнішнього, потім екструзія.
9. `VISUALSTYLES` → Shaded, `3DORBIT` → скріншот.
10. Експорт: `STLOUT` → вибрати тіло → Binary → `digit7_autocad.stl`.

## 3. Fusion 360 (Етап 2)

1. **New Component** → `Digit7`, активувати його.
2. **Create Sketch** → площина XY. **Line** по точках P1…P7 (вводити координати
   через Tab), замкнути контур. Finish Sketch.
3. **Extrude** профілю → `8 mm`, Operation: **New Body**.
4. **Create Sketch** на верхній грані цифри → **Text** (Arial, Bold):
   - МИКИТИЧ: Height 7, центр (35, 89), Angle 0;
   - МИХАЙЛО: Height 5.5, центр (37.7, 40.6), Angle 68.2°;
   - ВАСИЛЬОВИЧ: Height 5, центр (45.5, 37.5), Angle 68.2°.
5. **Extrude**:
   - МИКИТИЧ → `1.5 mm` назовні, Operation **Join**;
   - МИХАЙЛО → `-2 mm`, Operation **Cut**;
   - ВАСИЛЬОВИЧ → **All** (або `-10 mm`), Operation **Cut**.
6. Скріншот моделі (Home view, Shaded with visible edges).
7. Експорт: правою кнопкою на Body → **Save As Mesh** → STL (Binary), Refinement High → `digit7_fusion.stl`.

## 4. Ultimaker Cura (Етап 3)

1. Open File → `digit7_fusion.stl`. Покласти пласкою (нижньою) гранню на стіл.
2. Налаштування (Custom):
   | Параметр | Значення |
   |---|---|
   | Layer Height | **0.2 mm** |
   | Infill Density | **20 %** |
   | Generate Support | **Off** (нависань немає, у вирізах «мостів» немає) |
   | Build Plate Adhesion Type | **Brim** |
   | Матеріал | PLA (Generic) |
3. **Slice** → записати час друку та масу матеріалу (нижній правий кут).
4. **Preview** → Layer view: показати шари.
   - **Увігнутий** текст: верхні 2 мм (10 шарів) мають отвори у формі букв.
   - **Наскрізний** текст: отвори є в усіх шарах (стінки букв друкуються периметрами).
   - **Опуклий** текст: з'являється лише в останніх 1.5 мм (шари 41–48), а нижче суцільне тіло.
5. Скріншоти: панель налаштувань і підсумок (час, грами).

Орієнтовно (для перевірки своїх чисел): об'єм тіла ≈ 25.7 см³, тобто ≈ 10–15 г
PLA при 20 % заповнення. Точне значення бере Cura для конкретного принтера.
